1A · Axioms of probability

10 points · probability prerequisites (used throughout L16–L17)

Question 1 — expressions equal to P(A=0 | B=0)

Start from the definition and from Bayes' rule, then rewrite the denominator with the law of total probability.

P(A=0 | B=0) = P(A=0, B=0) / P(B=0)
= P(B=0 | A=0) P(A=0) / P(B=0)
P(B=0) = P(A=0, B=0) + P(A=1, B=0)
       = P(B=0 | A=0)P(A=0) + P(B=0 | A=1)P(A=1)

Check each option against those identities. Discard anything that divides by P(A=0) instead of P(B=0), or that drops a required term.

Hint 1. Options that equal the definition (joint over marginal of B) or Bayes' rule with a correctly expanded P(B=0) are keepers.
Hint 2. P(A,B)/P(A) is P(B|A), not P(A|B). P(B|A)P(A) is the joint, not the conditional. P(B|A) alone drops the prior.

Question 2 — always-true statements

  • The joint P(A=1, B=1) cannot exceed the marginal P(A=1).
  • For binary B: P(A=1) = P(A=1,B=1) + P(A=1,B=0) (partition).
  • Independence P(A,B)=P(A)P(B) is not always true.
  • P(A|B) ≥ P(A) is not always true (evidence can raise or lower a probability).
  • P(A=1 | B=1) = P(A=1,B=1)/P(B=1) ≥ P(A=1,B=1) because P(B=1) ≤ 1.

2A · Aircraft Bayes net

10 points · Lecture 16 BN semantics

Binary variables A, N, S ⇒ the full joint table has 2³ = 8 rows (Lecture 16 “Size of a Bayes Net”).

Lecture 16: a Bayes net encodes P(A, N, S) = P(A) P(N) P(S | A, N) because A and N are roots (no parents) and both point to S.
P(A=T, N=T, S=F) = P(A=T) P(N=T) P(S=F | A=T, N=T)
P(S=T) = Σa,n P(A=a) P(N=n) P(S=T | A=a, N=n)

Read P(S=T | ·) from the figure; use 1 − P(S=T | ·) when you need S=F. Sum over all four (A,N) pairs for the stall marginal.

2B · Satellite factors, arc reversal, inference

20 points · Lecture 16 topology + Lecture 17 factors

Factor multiply and marginalize (q10–q11)

You are given an evidence factor that forces D=T, P(D)=[F↦0, T↦1], and the CPT P(D|E). Lecture 17 “Join Factors”: for every assignment, multiply the matching entries.

unnormalized P(D, E) entry = evidence(D) × P(D | E)
Then sum out D to get a 2-entry factor over E (Lecture 17 “Eliminate”).
These factors are not yet normalized posteriors — the problem says so explicitly. Do not divide by a prior on E.

Arc reversal C ← E (q12)

Lecture 16 “Reverse Traffic” / causality: you may reverse an arrow if you replace the CPTs so the joint stays the same. Originally the net has parents(E) = {B, S} and parents(C) = {E}. After reversing E → C into C → E, C becomes a root (needs P(C)) and E gains C as an extra parent, so you need P(E | B, S, C).

You do not need a new table for D; D still depends only on E.

Inference expression for P(E=T | D=T, C=T) (q13)

Lecture 17 inference by enumeration / VE in equations:

P(E=T | D=T, C=T) ∝ P(D=T | E=T) P(C=T | E=T)
  × ΣB ΣS P(E=T | B, S) P(B) P(S)

Sum out the hidden parents of E; keep the evidence CPTs for D and C evaluated at the observed values. Watch for options that sum over D or C (those destroy the evidence) or that treat P(E|B,S) as if B and S were fixed without summing.

3B · Multiply and marginalize

10 points · Lecture 17 join + eliminate

multiply_tables(tables) → CPT  ·  marginalize(table, rvs) → CPT

multiply_tables

Lecture 17 Operation 1: the result is a factor over the union of all RVs. For every joint assignment of that union, multiply the value each input CPT contributes on its own variables.

all_rvs = unique RVs across tables (preserve order)
result table = ones(shape of all_rvs)
for assignment in iter_joint_values(all_rvs):
    value = 1
    for table in tables:
        value *= table.get(get_sub_assignment(all_rvs, assignment, table.rvs))
    result.set(assignment, value)
Use the helpers already in the notebook: iter_joint_values and get_sub_assignment. Do not normalize.

marginalize

Lecture 17 Operation 2: sum the numpy array along the axes of the RVs you are removing.

axes = tuple(table.rvs.index(rv) for rv in rvs)
new_table = table.table.sum(axis=axes)
new_rvs = [rv for rv in table.rvs if rv not in rvs]
return CPT(new_rvs, new_table)

This is one step of variable elimination on a two-node net:

marginal = normalize( marginalize( multiply(rain_model, evidence), {Rain} ) )

4 · Recover a minimal Bayes net

5 points · AI-enabled · Lecture 16 conditional independence

You are given the exact joint over X1…X10 in hidden_joint.npy. Find a DAG with 12 edges whose BN factorization reproduces that joint.

Lecture 16: the graph’s missing edges are conditional independences. X ⊥ Y | Z holds in the distribution iff P(X,Y|Z) = P(X|Z)P(Y|Z) (up to floating-point noise ~1e−15 on this exact table).

Suggested workflow (have an LLM help write the code)

  1. Skeleton (undirected edges). Start from the complete graph. Remove an edge X–Y when you find any conditioning set Z (among current neighbors) that makes X ⊥ Y | Z. This is the PC-algorithm idea from CI testing.
  2. Orient v-structures. For an unshielded triple X – Z – Y (no X–Y edge), if Z was not in the separator that removed X–Y, orient X → Z ← Y (collider).
  3. Propagate orientations with Meek-style rules (or try the few remaining undirected edges both ways) so the graph stays a DAG.
  4. Verify. For each node, estimate P(Xi | Pai) from the joint, multiply those CPTs, and check np.allclose against hidden_joint.
Submit only the edge list in q19_answer. Comment out slow scratch code before Gradescope upload. Several DAGs with the same skeleton but different reversible arrows can be correct.
Hint 1. Domains are small but the joint has >10⁵ entries — never paste the table into chat. Write numpy CI tests instead.
Hint 2. After order-0/1/2/3 conditioning, you should land on exactly 12 undirected edges. If you have more, your CI test’s broadcasting is probably wrong.
Hint 3. Unconditional independences include pairs like (X1,X6), (X6,X8), (X8,X9), (X9,X10). Colliders involving X2 and X4 are a good place to start orientations.
